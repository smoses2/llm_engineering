# Documentation

- `workspaces.md`: selecting workspaces and separating configuration from results
- `configuration.md`: YAML catalogs, definitions, sources, models, and templates
- `evaluation-workflows.md`: retrieval, judgments, frozen answers, and reports
- `artifact-model.md`: datasets, lifecycle, identity, lineage, and cleanup
- `cli-reference.md`: all commands, global options, and exit codes
- `examples.md`: safe example configuration and prompts
- `architecture.md`: package and pipeline architecture
- `troubleshooting.md`: common configuration, API, lifecycle, and recovery errors
- `development.md`: installation, quality checks, tests, and conventions

Start with `workspaces.md`, then configure an evaluation through
`configuration.md` and run it using `evaluation-workflows.md`.
